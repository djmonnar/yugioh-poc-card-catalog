# Power of Chaos 한국어 모드 카드 도감

**[도감 열기](https://djmonnar.github.io/yugioh-poc-card-catalog/)**

설치된 한국어 모드의 전체 카드 **1,136종**을 살펴보고, 카드풀의 다음 변경을 검토하는 도감입니다. 일반 카드 1,131장과 토큰·특수 참조 카드 5종을 포함합니다.

2026-10-08: 게임에 연결한 Claude 효과 모듈은 **170장 판**입니다. 파멸의 의식의 묘지 효과 설명과 미해결 효과의 검토 메모를 갱신했습니다. 이 판에는 기존 카드 33장의 AI 사용 판단도 포함됩니다. 통합 실행 파일에서 2,423항목을 검사했으며, 실제 게임 화면의 연출·선택 순서까지 확인했다는 뜻은 아닙니다. 카드 ID와 기존 온라인 덱·스토리의 호환성은 유지합니다.

기믹 분류(듀얼·유니온·마력 카운터·LV)와 카드군·덱 테마 필터를 추가했습니다. 카드 상세에서
같은 묶음의 카드, 지원 카드, LV 관계로 이동할 수 있습니다. 소속과 지원은 별도로 표시합니다.
예: [라이트로드 묶음](https://djmonnar.github.io/yugioh-poc-card-catalog/#group-lightsworn).
이 분류는 공식 카드의 유형을 설명하며, 게임에서 원본 효과를 모두 복원했다는 뜻은 아닙니다.

## 내가 만드는 카테고리와 관련 카드

이메일 로그인 후 **카드 찾기 → 내 카테고리·태그 → 새 카테고리**에서 원하는 분류를 만듭니다.
카드 상세의 **카테고리·링크 편집**에서 태그를 체크하고, 카드 이름으로 관련 카드를 검색해 연결한 뒤
**카테고리·링크 온라인 저장**을 누릅니다. 카드마다 태그 12개와 관련 카드 20장까지 저장할 수 있습니다.

카드 찾기에서 태그를 여러 개 체크하면 모두 포함한 카드만 표시합니다. 검색창에 태그 이름을 입력해도 찾을 수 있습니다.
관련 카드 링크는 양쪽 상세에 표시되며, 태그를 누르면 같은 태그의 카드 목록으로 이동합니다.
AI 덱 편집기의 **내 카테고리·태그**에서도 같은 분류를 사용할 수 있습니다. 도감에서 수정한 뒤에는 **태그 새로 불러오기**를 누릅니다.
분류와 링크는 온라인에 저장되어 다른 기기에서도 보입니다. 읽기는 로그인 없이 가능하며 편집은 기존 소유자 이메일 인증을 사용합니다.
다른 카드로 교체된 슬롯에 이전 카드의 태그나 링크를 자동으로 물려주지 않습니다.

## 의견 보내는 방법

1. 카드 이름·효과로 검색하거나 등급, 카드 종류, 종족, 속성, 현재 제한으로 걸러봅니다.
2. 카드를 누르면 현재 모드의 한국어 설명, 능력치, 등급 근거, 공식 DB 연결을 볼 수 있습니다.
3. 원하는 **레어 등급**, **교체 후보와 대체 카드**, **덱 제한 1·2장**을 선택하고 이유를 적습니다. 금지 0장·무제한 3장 의견도 가능합니다.
4. 의견은 입력할 때 이 브라우저에 자동 저장됩니다. **내 검토**에서 작성한 카드만 모아 볼 수 있습니다.
5. **의견 내보내기 → 검토 JSON 내려받기**로 파일을 저장하고 Codex 채팅에 첨부합니다. **전달할 내용 복사**로 텍스트를 붙여넣어도 됩니다.

다른 기기·브라우저에서 이어서 검토하려면 JSON을 **검토 JSON 불러오기**로 가져옵니다. 기존 의견을 먼저 백업한 뒤 같은 카드의 의견을 합칩니다. 불러오기 전 백업도 내려받을 수 있습니다. 브라우저 저장소를 지우면 의견이 사라지므로 JSON 파일을 보관해 주세요. 의견은 GitHub로 자동 전송되지 않습니다.

전달한 의견을 비우려면 **의견 내보내기 → 의견 전체 초기화**를 누릅니다. 확인창에서 승인하면 현재 의견과 이전 카드 의견을 백업한 뒤 비웁니다. **초기화 전 의견 복원**과 **초기화 전 백업 JSON 내려받기**를 사용할 수 있고, 새로 작성한 의견은 복원할 때 유지합니다. 백업이나 저장에 실패하면 초기화를 취소합니다. 내보내기만 하면 의견은 그대로 남습니다.

요청한 등급·제한이 도감에 반영되어도 기존 검토 의견을 자동으로 지우지 않습니다. 이전 기준과 요청 값을 보존하며, 직접 초기화하거나 해당 카드의 의견을 지울 때까지 유지합니다.

사이버 드래곤의 레벨 4 오류를 5로 바로잡는 등 동일 카드의 확인된 수정은 정확한 이전 식별값을 연결해 의견을 유지합니다. 같은 슬롯에 다른 카드를 교체한 경우에는 이 연결을 사용하지 않습니다.

효과·교체·제한 요청은 검토 의견으로 보관합니다. **등급·상점 판매 여부·뽑기 포함 여부**는 이메일 로그인 후 카드 상세의 **게임 설정 바로 저장**에서 직접 바꾸고 저장할 수 있습니다. 일반 등급에서 상점 판매 체크를 끄면 구매 목록에서 빠지며, 보유한 카드의 판매는 계속 가능합니다. 뽑기 체크를 끄면 가챠·듀얼 승리·스토리의 무작위 카드 보상에서 제외합니다. 가격은 UR 300/150, SR 200/100, R 100/50, N 50/25입니다(구매/판매).

**L · 레전드**는 지정한 스토리 카드 보상으로만 얻습니다. 구매·판매·가챠·모든 무작위 카드 보상에서 제외하며, 상점과 뽑기 체크는 자동으로 꺼집니다. 첫 보상뿐 아니라 반복 보상에도 지정할 수 있으며 보유 1장 제한은 없습니다. 레어 등급과 덱 금제는 별개입니다.

저장한 설정은 도감에 바로 반영됩니다. PC에서는 다음 창모드 실행 때 확인하며, 새 상점 서버는 10초마다 갱신합니다. 기존 상점은 한 번 다시 열어 주세요. 이미 만들어진 게임 카드 그림의 레어 마크는 별도 이미지 갱신이 필요합니다. 설정 변경에는 소유자의 인증된 이메일이 필요하며 다른 방문자는 읽기만 할 수 있습니다.

## 플레이어 금제 바로 저장

카드 상세의 **플레이어 금제 바로 저장**에서 일반 듀얼과 스피드 듀얼을 따로 정하고 **금제 온라인 저장**을 누릅니다. 이메일 로그인한 편집자만 변경할 수 있으며 저장한 금제는 도감·AI 덱의 참고 표시와 다음 게임 실행의 카드 배지·카드 추가 경고·BACK 검사에 반영됩니다.

- 일반 듀얼: 금지(0장), 제한(1장), 준제한(2장), 제한 없음(동명 3장). 게임에서 일반 금제 적용 옵션을 켰을 때 적용합니다.
- 스피드 듀얼: 금지(플레이어 사용 불가), 제한 1·2·3 그룹, 제한 없음. 같은 제한 그룹의 카드 종류를 모두 합산해 각각 1·2·3장까지 넣을 수 있습니다. ‘제한 3 그룹’과 ‘제한 없음’은 서로 다릅니다.
- **기본값**은 해당 규칙의 원래 금제로 되돌립니다. 카드 등급·판매·뽑기 설정은 바뀌지 않습니다.
- **AI는 두 금제에서 제외**됩니다. 같은 카드 3장, 해피 레이디 계열 합산 3장, 덱 크기·배치 조건은 유지됩니다.

온라인 연결이 끊기면 PC는 마지막으로 가져온 금제를 유지합니다. 카드가 교체되어 신원이 달라진 경우 이전 카드의 금제를 자동으로 넘기지 않습니다. 직접 실행 파일을 실행하지 말고 기존 한국어 창모드 바로가기로 시작해야 온라인 설정을 가져옵니다.

## AI 덱 만들기

상단 **AI 덱 만들기** 또는 [AI 덱 편집기](https://djmonnar.github.io/yugioh-poc-card-catalog/ai-decks.html)에서 상대 덱을 직접 구성할 수 있습니다. 모바일에서는 **카드 찾기 / 내 AI 덱**을 전환합니다.

- 카드 그림을 누르면 현재 모드의 효과를 확인하고, 메인·융합·사이드 덱에 추가할 수 있습니다. 카드 그림과 덱 목록의 금지·제한 1·2·3 배지는 선택한 규칙의 **플레이어 금제**입니다. AI는 금제를 적용하지 않으며 같은 카드 3장·해피 레이디 계열 합산 3장과 덱 크기·배치 규칙은 유지합니다.
- 여러 덱을 만들고 이름·희망 난이도·승리 목표·우선 효과·콤보·피해야 할 행동을 적습니다.
- **기존 상대 덱에서 시작하기**에서 난이도와 이름을 붙인 상대 덱 42종(일반 21종·스피드 시험판 21종)을 확인할 수 있습니다. 카드 신원·장수·배치가 맞지 않는 구성은 확인 항목에 표시합니다.
- 이메일 로그인 후 **이 덱 온라인 저장**에서 적용 상대를 고르고 **이 상대 덱으로 저장**을 누릅니다. GitHub 이슈를 작성하는 단계는 없습니다. 다른 기기에서는 **온라인 덱 불러오기**를 사용합니다.
- PC의 기존 한국어 창모드 바로가기로 다음 실행 시 검사를 통과한 상대 덱을 백업 후 적용합니다. 플레이 중에는 상대 파일을 바꾸지 않습니다. 이름·콤보 메모는 저장하지만 AI 행동 코드를 자동 생성하지 않습니다. 덱 구성이 유효하다는 표시는 AI의 플레이 검증 완료를 뜻하지 않습니다.
- 일반은 40~80장, **듀얼링크스 기획 · 20~30장**은 스피드 시험판 대상입니다. 각 대상의 규칙이 같은 덱만 저장할 수 있습니다. 융합·사이드는 각각 15장까지 지원합니다.
- 덱은 카드 검토 의견과 별도 저장합니다. JSON으로 다른 기기에서 이어서 편집할 수 있고, 불러오기 전 기존 덱을 백업합니다. 기존 카드가 교체되면 이전 카드를 새 카드에 자동 배정하지 않고 미일치 상태로 보존합니다.

온라인으로 저장한 상대 덱 이름·구성·메모는 공개됩니다. 플레이어 보유 카드·세이브·골드는 클라우드에 올리지 않습니다. 브라우저 초안과 검토 의견은 기존처럼 기기에 보관합니다.

## 등급 초안

| 등급 | 기준 | 구매 기준 가격 | 판매 기준 가격 | 일반 카드 수 |
|---|---|---:|---:|---:|
| L | 지정 스토리 보상 전용 · 반복 획득 가능 | 구매 불가 | 판매 불가 | 온라인 지정 |
| UR | 강한 범용 카드, 전체 제거, 주요 키카드 | 300 | 150 | 59 |
| SR | 주요 딜러, 제거, 특화 지원 | 200 | 100 | 178 |
| R | 실용적인 기본 카드, 테마 카드 | 100 | 50 | 501 |
| N | 단순하거나 쓰기 까다로운 카드 | 50 | 25 | 393 |

기존 모드 상점의 자체 등급을 초안으로 사용했습니다. 공식 상품의 수록 레어도와는 별개입니다. 일반 능력치에 따른 자동 분류와 주요 카드의 수동 검토가 섞여 있으므로 조정할 수 있습니다. 토큰·특수 5종은 참고용 N이며 가격·덱 제한 대상이 아닙니다.

2026-10-06 갱신에서는 사용자의 등급 의견 217건과 덱 제한 의견 5건을 반영했습니다. 환상소환사 2장, 죽음의 덱 파괴 바이러스·데블 프랑켄·혼돈의 흑마술사는 각각 1장, 희생의 제물은 금지이며 모드의 금지·제한 옵션을 꺼도 유지됩니다.

2026-10-08에는 Claude 169b의 169장 효과·AI 판과 새 카드 21장을 실제 설치 파일에 통합했습니다. 실행 파일에 실린 효과 코드에서 2,335개 assertion을 확인하고, 새 슬롯의 저장·재열기와 기존 스토리·마력 카운터·레어도·금제 연결을 검사했습니다. 새 카드는 기본 R이며 판매 체크는 꺼져 있습니다. 도감에서 등급·판매·뽑기를 조정할 수 있습니다. 설명에 적힌 미지원·차이·사용법과 실제 플레이 확인은 별개입니다.

카드가 추가되거나 같은 카드의 인쇄 능력치가 정정돼도 기존 온라인 AI 덱·스토리 참조를 유지합니다. 알려진 이전 도감과 명시된 카드 식별 별칭만 받아들이며, 다른 카드로 교체된 경우에는 다시 선택해야 합니다.

## 스토리 제작

`story.html`에서 전투 순서·상대·일반/스피드 AI 덱·대사·첫/반복 승리 보상을 작성할 수 있습니다.
보상 카드 검색과 캐릭터 초상화·스킬 설정을 지원하며, 도감과 같은 이메일 로그인으로 온라인 저장합니다.
작성 자료는 JSON과 콘텐츠 파이프라인 묶음으로 내보냅니다. 자세한 사용법은 [STORY-AUTHORING.md](STORY-AUTHORING.md)를 읽습니다.
게임의 시나리오 선택·대사·전투·캐릭터 스킬·첫/반복 보상과 진행 저장에 연결돼 있습니다. 런타임 연결 검사와 실제 플레이 확인은 구분해서 보고합니다.

가격은 해당 등급의 기준 가격입니다. 초기 상점 상품은 70종이며, 로그인한 소유자가 카드별 판매 체크로 늘리거나 줄일 수 있습니다. 초기 상품에는 융합 몬스터 11종을 포함하며, 확인한 소재·입수 경로도 표시합니다. 카드의 공식 인쇄 효과를 구현된 효과로 가정해서 등급을 올리지 않았습니다. 위 등급 수는 기본 데이터 기준으로, 온라인 조정 후에는 달라집니다.

## 데이터와 효과의 기준

- 이름·한국어 설명·종족·속성·레벨·ATK/DEF는 실제 설치된 카드 자료에서 읽었습니다.
- 현재 제한은 모드의 금지·제한 적용 옵션을 켠 상태의 덱 투입 매수입니다. 보유 매수 제한이나 최신 공식 금제와는 별개입니다. 카드 상세에는 옵션을 끈 경우도 표시합니다.
- 공식 카드 DB로의 연결은 기존 매칭 자료를 사용합니다. 매칭이 확인되지 않은 카드에는 표시가 있습니다.
- 알려진 원본 효과와의 차이는 **공식 효과 차이·부분 복원**에서 따로 볼 수 있습니다. 공식 이름 매칭 미확인까지 포함하려면 **효과·이름 검토 대상**을 고릅니다. 전체 효과 구현을 모두 검증한 목록은 아닙니다.
- 프로토 사이버 드래곤과 엘리멘틀 히어로 플리즈마의 현재 설명은 융합 소재 대체입니다. 원래 이름 취급/이름 변경 효과와 다른 것으로 표시했습니다.
- 사이버 드래곤의 릴리스 없는 소환 설명, 츠바이의 지연 파괴 설명, 사이버 트윈의 소재·효과는 복원 검토 대상입니다.
- 펠그란트 드래곤의 부활 이력·공격력 상승, 사이버 엔드 드래곤의 사이버 드래곤 3장 지정 소재·관통 효과를 복원했습니다. 코드 검사를 통과했고 실전 듀얼 확인은 대기 중이며, 나머지 의견의 효과 복원이 완료된 것은 아닙니다.
- 프리즈마, 플레임 윙맨, 썬더 자이언트, 붉은 눈의 암룡, 일부 마력 카운터 카드의 미복원·부분 지원도 메모로 구분했습니다.
- 도감은 스냅샷입니다. 게임에 카드·효과·제한 변경을 적용한 뒤에는 데이터를 다시 내보내야 합니다.

참고: [프로토 사이버 드래곤 공식 DB](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=6588&ope=2&request_locale=ko), [엘리멘틀 히어로 플리즈마 공식 DB](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=7491&ope=2&request_locale=ko).

사이버 계열 비교: [사이버 드래곤](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=6390&ope=2&request_locale=ko), [츠바이](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=8646&ope=2&request_locale=ko), [트윈](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=6396&ope=2&request_locale=ko), [엔드](https://www.db.yugioh-card.com/yugiohdb/card_search.action?cid=6397&ope=2&request_locale=ko).

## 파일

- `data/cards.json`: 도감 데이터와 카드풀 버전 해시
- `data/cards.csv`: 전체 목록과 검토 입력용 빈 열. Excel에서 확인·수정한 CSV를 채팅에 보내도 됩니다.
- `assets/cards/*.webp`: 설치된 카드 앞면의 200×290 도감 미리보기
- `review-core.js`: 카드 식별·의견 정규화·내보내기/불러오기
- `review-storage.js`: 초기화 전 백업과 저장 실패 시 의견 보존
- `tests/`: 의견 왕복, 카드 교체 뒤 식별, 전체 목록과 공개 자료 검사

검토 JSON에는 카드 번호와 내부 ID뿐 아니라 이름·속성을 포함한 **카드 식별 키**와 도감 버전이 들어갑니다. 기존 카드가 교체되어 같은 슬롯·ID를 재사용해도 이전 의견이 새 카드에 자동 적용되지 않습니다. 일치하지 않는 의견은 내보내기 파일에 별도로 보존합니다.

이 저장소에는 게임 실행 파일, 리소스 아카이브, 플레이어 덱·세이브, 보유 목록, 골드 기록, 개인 파일 경로를 포함하지 않습니다. 정적 도감·검토·초안 편집은 로그인 없이 사용하며, 온라인 상대 덱과 등급·판매 설정은 Supabase를 사용합니다. 공개 설정에는 publishable 키만 포함합니다. 개인 이메일 허용 목록과 변경 이력은 비공개 DB에 둡니다.

## 로컬 실행과 검사

```sh
python -m http.server 8765 --bind 127.0.0.1
# http://127.0.0.1:8765/ 열기
node --test tests/*.test.js
```

`file://`로 직접 열면 브라우저가 JSON 읽기를 차단할 수 있으므로 정적 서버나 GitHub Pages를 사용합니다. 일반 실행·Node 검사는 설치된 SDK 번들을 사용합니다. SDK를 다시 빌드할 때는 `npm ci --ignore-scripts` 후 `npm run build:cloud`를 실행합니다. 클라우드 설치·검사는 [Supabase 안내](mod-tools/supabase/README.md)를 참고합니다.

## 권리와 출처

비공식 팬 프로젝트입니다. Yu-Gi-Oh! 카드 이름·텍스트·일러스트의 권리는 원작 및 각 권리자에게 있습니다. 미리보기는 사용자의 설치 모드에 적용된 카드 앞면을 WebP로 변환한 것입니다. 이 저장소는 해당 이미지나 원작 데이터의 소유권·재배포 라이선스를 부여하지 않습니다.
